# Upload checklist (Ian does these by hand)

Nothing here has been published, no account was created and nothing was pushed.

1. Sign in or create a CurseForge author account (https://authors.curseforge.com).
2. Create a project:
   - Game: Minecraft, class: Mc Mods
   - Name: Starfall
   - Summary: paste `summary.txt`
   - Logo: upload `logo.png`
   - Description: paste `description.md` (Markdown editor) or `description.html` (WYSIWYG source view). `description.txt` is the plain version.
   - Main category: Magic (suggested). Extra: Food, Cosmetic (suggested, pick what you like)
   - License: MIT License
   - Source link: https://github.com/esquivel-stuff/starfall-fabric-mod
3. Images tab (optional): upload the pictures in `screenshots/`.
4. Upload the file `starfall-1.0.0+1.21.1-fabric.jar`:
   - Display name: Starfall 1.0.0
   - Release type: Release
   - Game version: 1.21.1, mod loader: Fabric, Java 21
   - Changelog: paste `changelog-1.0.0.md`
   - Related projects: Fabric API as a Required Dependency
5. `git push` the local commit so the image links in the description (raw.githubusercontent.com, main branch) show the updated wand tooltip.
6. Wait for moderation review.
